# Freshfood Client

Freshfood Client is a React application built with TypeScript, Vite, and Tailwind CSS.

## Setup

From the `frontend` directory, install the dependencies and start the development server:

```bash
npm install
npm run dev
```

Vite prints the local URL when the development server starts. By default, it is `http://localhost:3000`.

## Checks

Run the linter:

```bash
npm run lint
```

Create a production build:

```bash
npm run build
```
